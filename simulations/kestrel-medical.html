    Where the times come from

    Times are the recorded save time of each output file in the Kestrel Medical folder, the approval snapshots in History/, and the git commit times. A file that was saved again later shows its last save, so a few first drafts started earlier than shown.

    SourceUsed for
    File save timesEach output's save time in the project folder (or its first git commit, where that is earlier)
    History snapshotsStage approvals: the moment the approved version was saved
    Session logsAgent run time: only the time Claude was working inside a reply, with any single wait over 5 minutes cut to 5. Reading and review time between replies is left out. Each step goes to the agent whose files it touched; agent instructions, guides and personas count as improving the agents
    TimelineSteps are spaced by agent run time, not clock time, so long breaks and review time take no space. Each step also shows when its output was saved
    InteractionsEach message Human typed to the agents in the sessions for this project, counted up to each step. Commands like /wrap and system notes are left out
    TokensEvery model call in the run's session log, up to each step: new input, cached re-reads and output. The main chat counts as Ovy and each subagent as its agent. The test stakeholder and helpers are left out
